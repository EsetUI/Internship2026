## Day 7 - Mini-Project Planning

Day 7 starts the project phase. The main skill today is scope control.

### Goals

Students should be able to:

* choose a project that is small enough to finish
* describe the minimum working version
* split the work into small tasks
* identify stretch goals separately from the required core

### Practical Task

1. Read the project briefs in [../mini-projects/README.md](../mini-projects/README.md).
2. Choose one project.
3. Write down the minimum required features.
4. List 3 to 5 implementation tasks.
5. Create a branch for project work.

### Deliverables

* chosen project brief
* short task breakdown
* project branch created
