## Day 9 - Testing And Polish

Day 9 is about finishing work instead of endlessly adding new features. The two language versions should now behave as similarly as practical.

### Goals

Students should practice:

* manual testing with different inputs
* fixing edge cases
* improving user messages
* writing a short project README
* preparing a clear demo flow
* comparing Python and C++ behavior against the same test cases

### Practical Task

1. Test both project versions with the same normal and incorrect input cases.
2. Fix at least one bug or rough edge in each version.
3. Add a short README that explains how to run each version.
4. Remove incomplete features that are not ready.

### Deliverables

* cleaner and more aligned project behavior
* short README for each implementation
* ready-to-demo Python and C++ versions
