## Day 6 - Cross-Language Review And Debugging

Day 6 focuses on comparing the Python and C++ solutions to the same tasks and tightening them until the behavior is aligned.

### Goals

Students should practice:

* reading error messages carefully
* reproducing a bug before changing code
* comparing two implementations of the same requirement
* improving variable names and function names
* simplifying duplicated logic
* giving and receiving review feedback

### Practical Task

1. Run the Day 3, Day 4, and Day 5 tasks in both languages using the same test cases.
2. Note any differences in output, validation, or behavior.
3. Each student reviews the other implementation.
4. Each student fixes at least one inconsistency or issue in their own branch.

### Example Improvements

* validate empty input
* align output wording between languages
* rename unclear variables
* move repeated logic into a function
* improve the printed error message
* tighten pull request description or commit naming

### Deliverables

* one fix or refactoring commit per student
* one review discussion on each branch
* closer behavior alignment between the Python and C++ versions
