## Day 7 - Mini-Project Planning

Day 7 starts the project phase. Both interns should choose the same project brief, but implement it in different languages.

### Goals

Students should be able to:

* choose one project that is small enough to finish in two languages
* describe the minimum working version
* split the work into small tasks
* identify stretch goals separately from the required core

### Practical Task

1. Read the project briefs in [../mini-projects/README.md](../mini-projects/README.md).
2. Choose one shared project brief for both interns.
3. Write one shared minimum required feature list.
4. List 3 to 5 implementation tasks that both language versions must cover.
5. Create one Python branch and one C++ branch for project work.

### Deliverables

* chosen shared project brief
* one shared task breakdown
* separate Python and C++ project branches
