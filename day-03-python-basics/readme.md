## Day 3 - Python Applied Track

Day 3 should not be a Python syntax lesson for a student who already knows Python basics. Use it as an applied implementation and code-quality day.

### Goals

Students should practice:

* structuring a small command-line tool
* validating input and error cases
* separating logic into clear functions
* improving console output and usability
* explaining changes clearly in a pull request

### Suggested Exercises

Use these files from [../python-exercises/README.md](../python-exercises/README.md):

* `02_temperature_converter.py`
* `03_number_stats.py`

### Mixed-Track Role Split

* Python-proficient student: owns implementation and refactoring.
* C++-proficient student: reviews requirements, runs the script, and comments on behavior and edge cases.

### Practical Task

1. Choose one starter program.
2. Add one behavior change and one code-quality improvement.
3. Test both normal input and invalid input.
4. Commit the change and explain it in a pull request.

### Good Challenge Ideas

* add stronger input validation
* support a repeated menu loop
* add another conversion or statistic
* improve output formatting and help text
* extract parsing or formatting into helper functions

### Deliverables

* one meaningful Python pull request
* one review comment from the other student or a mentor
