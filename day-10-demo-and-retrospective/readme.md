## Day 10 - Demo And Retrospective

Day 10 closes the internship with a short demonstration and reflection.

### Goals

Students should be able to:

* run the finished project without help
* explain the main features clearly
* describe one technical problem they solved
* describe one thing they would improve next

### Suggested Demo Structure

1. Introduce the project in one sentence.
2. Show how to run it.
3. Demonstrate the main feature.
4. Explain one design or debugging decision.
5. Summarize what was learned during the internship.

### Deliverables

* short live demo or presentation
* final pull request or merged project branch
* brief retrospective discussion with mentors
