# Evaluation Rubric

Use this rubric as a lightweight guide for feedback.

## 1. Environment And Tool Usage

* `0` - cannot work independently with the setup
* `1` - can work with help
* `2` - can use tools independently

## 2. Git And GitHub Workflow

* `0` - does not use branches or pull requests correctly
* `1` - uses workflow with reminders
* `2` - uses workflow independently and clearly

## 3. Code Quality

* `0` - code often does not run or is very hard to read
* `1` - code works but needs cleanup or guidance
* `2` - code is clear, small, and understandable

## 4. Problem Solving

* `0` - gives up quickly when blocked
* `1` - can continue with support
* `2` - tries sensible debugging steps before asking for help

## 5. Communication

* `0` - progress is unclear or missing
* `1` - basic updates are provided
* `2` - progress, blockers, and decisions are explained clearly

## 6. Final Project Delivery

* `0` - project is incomplete or cannot be demonstrated
* `1` - project works partly but lacks polish
* `2` - project works, is explainable, and is presented clearly

The rubric is intentionally simple. It should guide feedback, not replace mentor judgment.
