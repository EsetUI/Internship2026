# Student Checklist

## Before Day 1

* Bring a laptop and charger.
* Make sure you can log in to GitHub.
* Install Git, Python, and an editor.
* Confirm you can open a terminal.

## At The Start Of Each Day

* Read the task for the day.
* Pull the latest changes if needed.
* Ask if anything in the task is unclear.
* Decide what the minimum finished result should be.

## Before Commit

* Run the program.
* Check the changed files.
* Make sure there is no accidental debug output or unrelated edit.
* Write a commit message that says what changed.

## Before Pull Request

* Re-read the task.
* Make sure the program still works.
* Explain the change in one or two sentences.
* Be ready to answer mentor questions.

## Before Final Demo

* Make sure the project starts cleanly.
* Prepare a short explanation of what the program does.
* Be able to describe one problem you solved.
* Be able to describe one thing you would improve next.
