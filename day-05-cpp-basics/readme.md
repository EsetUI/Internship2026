## Day 5 - C++ Applied Track

Day 5 should not re-explain loops or variables to a student who already knows C++ basics. Use it as a delivery, refactoring, and robustness day.

### Goals

Students should practice:

* compiling and running a C++ program
* structuring code with clear functions
* handling invalid input safely
* improving console output and usability
* explaining implementation choices in a pull request

### Suggested Exercises

Use these files from [../cpp-exercises/README.md](../cpp-exercises/README.md):

* `02_number_stats.cpp`
* `03_guess_number.cpp`

### Mixed-Track Role Split

* C++-proficient student: owns implementation and refactoring.
* Python-proficient student: reviews behavior, edge cases, and user-facing output.

### Practical Task

1. Choose one starter program.
2. Add one feature and one robustness improvement.
3. Compile and run it with both normal and incorrect input.
4. Commit and push the change with a clear description.

### Good Challenge Ideas

* add retry logic after bad input
* extract repeated output into helper functions
* improve prompts and result formatting
* add replay support or another operation
* document build and run steps in the pull request

### Deliverables

* one meaningful C++ pull request
* one review comment from the other student or a mentor
