## Day 6 - Debugging And Code Review

Day 6 focuses on how programmers improve code after it already works.

### Goals

Students should practice:

* reading error messages carefully
* reproducing a bug before changing code
* improving variable names and function names
* simplifying duplicated logic
* giving and receiving review feedback

### Practical Task

1. Python student reviews the C++ branch for behavior, clarity, and edge cases.
2. C++ student reviews the Python branch for behavior, clarity, and edge cases.
3. Each student fixes at least one review finding in their own code.
4. Each branch gets one follow-up commit after review.

### Example Improvements

* validate empty input
* rename unclear variables
* move repeated logic into a function
* improve the printed error message
* tighten pull request description or commit naming

### Deliverables

* one fix or refactoring commit per student
* one review discussion on each branch
