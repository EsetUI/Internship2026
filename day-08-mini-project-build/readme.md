## Day 8 - Mini-Project Build

Day 8 is for implementation. The target is a first working version, not perfection.

### Goals

Students should focus on:

* getting the main feature working first
* committing in small steps
* asking for help when blocked
* keeping the project simpler than originally imagined

### Practical Task

1. Implement the minimum working version from Day 7.
2. Commit after each meaningful step.
3. Push progress to the repository.
4. Ask for mentor review before adding stretch features.

### Deliverables

* one working project version
* several small commits showing progress
