## Day 10 - Demo And Retrospective

Day 10 closes the internship with a short demonstration and reflection. The final demo should show the same project solved in Python and C++.

### Goals

Students should be able to:

* run the finished project without help
* explain the main features clearly
* describe one technical problem they solved
* describe one thing they would improve next
* explain at least one tradeoff between the Python and C++ versions

### Suggested Demo Structure

1. Introduce the shared project in one sentence.
2. Show how to run the Python version.
3. Show how to run the C++ version.
4. Demonstrate the same core feature in both.
5. Explain one design or debugging decision and one difference between the two implementations.

### Deliverables

* short live demo or presentation covering both versions
* final Python and C++ project branches or pull requests
* brief retrospective discussion with mentors
