## Day 4 - Python Problem Solving

Day 4 continues the Python track with problem solving, refactoring, and edge-case handling rather than syntax review.

### Goals

Students should practice:

* splitting logic into functions
* parsing and validating input
* working with lists and strings
* printing readable results
* improving maintainability without changing the core goal

### Suggested Exercises

Use these files from [../python-exercises/README.md](../python-exercises/README.md):

* `03_number_stats.py`
* `04_word_counter.py`

### Mixed-Track Role Split

* Python-proficient student: owns implementation, feature work, and refactoring.
* C++-proficient student: acts as reviewer, tester, and requirement checker.

### Practical Task

1. Choose one program as the main task.
2. Add one feature and one maintainability improvement.
3. Test at least three different inputs, including one invalid case.
4. Open a pull request and ask for review.

### Stretch Ideas

* ignore empty words
* sort results before printing
* allow repeated execution in one run
* support reading text from a file
* separate parsing and display logic more clearly

### Deliverables

* one Python script extended beyond the starter behavior
* one pull request with review feedback addressed
