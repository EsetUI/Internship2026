# Calculator Project Brief

## Goal

Build a small command-line calculator that performs basic arithmetic operations.

## Minimum Required Features

* ask the user for two numbers
* ask for an operation such as `+`, `-`, `*`, or `/`
* print the result
* handle division by zero safely

## Stretch Ideas

* allow repeated calculations in a loop
* support more operations such as power or modulo
* keep a short calculation history

## Good Done Definition

The project is done when a user can run it, choose an operation, and get the correct result without crashing.
