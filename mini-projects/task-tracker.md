# Task Tracker Project Brief

## Goal

Build a small console program for adding and listing tasks.

## Minimum Required Features

* add a task
* list current tasks
* mark a task as done
* quit the application cleanly

## Stretch Ideas

* delete tasks
* save tasks to a file
* filter done vs not done tasks

## Good Done Definition

The project is done when a user can manage a few tasks from a simple text menu without errors.
