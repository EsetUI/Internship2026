# Mini Projects

The second week of the internship should end with one small but finished project.

## Project Selection Rules

Choose a project that:

* can be explained in one sentence
* has a clear minimum working version
* can be demonstrated in under 5 minutes
* does not depend on a complex framework

## Suggested Project Briefs

* [calculator.md](calculator.md)
* [quiz-app.md](quiz-app.md)
* [task-tracker.md](task-tracker.md)

## Expected Deliverables

Each project should include:

* source code
* a short README with run instructions
* at least one reviewed pull request
* a short final demo

## Suggested Workflow

1. Choose one brief.
2. Define the minimum working version.
3. Create a branch.
4. Build the core feature first.
5. Add only small extras if the core already works.
