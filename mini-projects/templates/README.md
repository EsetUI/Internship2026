# Project Templates

These templates are intentionally small. They are meant to provide structure, not to solve the project.

## Available Templates

* [python-cli-template/main.py](python-cli-template/main.py)
* [cpp-cli-template/main.cpp](cpp-cli-template/main.cpp)

## How To Use A Template

1. Copy the template into a new project folder.
2. Rename the project and update the messages.
3. Replace the placeholder menu actions with real logic.
4. Add a short README with run instructions.
