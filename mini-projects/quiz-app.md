# Quiz App Project Brief

## Goal

Build a command-line quiz with several questions and a final score.

## Minimum Required Features

* store at least 5 questions
* ask the user one question at a time
* check answers
* print the final score

## Stretch Ideas

* shuffle the questions
* show correct answers at the end
* allow multiple quiz categories

## Good Done Definition

The project is done when a user can complete the quiz from start to finish and see a correct final result.
