# Task Manager


# Requirements

* add a task
  
* list current tasks
  
* mark task as done
  
* quit the app cleanly


# Steps

1. console display for the manager

2. menu
   
3. task list
   
4. add a task
   
5. print tasks
   
6.  mark as done
    
7.  quit
   


# Optional

* delete tasks
  
* save tasks to a file
  
* filter completed vs not completed tasks
