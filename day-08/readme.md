## Day 8 - Mini-Project Build

Day 8 is for implementation. The target is a first working version of the same project in Python and C++.

### Goals

Students should focus on:

* getting the main feature working first
* committing in small steps
* asking for help when blocked
* keeping the project simpler than originally imagined
* keeping both language versions aligned on core features

### Practical Task

1. Implement the minimum working version from Day 7 in Python and C++.
2. Keep the core feature list aligned across both versions.
3. Commit after each meaningful step.
4. Push progress to the repository and ask for mentor review before adding stretch features.

### Deliverables

* one working Python version
* one working C++ version
* several small commits showing progress
