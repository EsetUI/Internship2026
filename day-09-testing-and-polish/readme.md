## Day 9 - Testing And Polish

Day 9 is about finishing work instead of endlessly adding new features.

### Goals

Students should practice:

* manual testing with different inputs
* fixing edge cases
* improving user messages
* writing a short project README
* preparing a clear demo flow

### Practical Task

1. Test the project with normal and incorrect input.
2. Fix at least one bug or rough edge.
3. Add a short README that explains how to run the project.
4. Remove incomplete features that are not ready.

### Deliverables

* cleaner project behavior
* short project README
* ready-to-demo project state
