## Day 1 - Environment Preparation and GitHub Cooperation

The first day makes sure every student can use the development environment and complete a basic GitHub workflow without getting blocked by setup problems.

### Goals

By the end of Day 1, students should be able to:

* open the repository in a code editor
* use a terminal for basic commands
* verify Git, Python, and a C++ compiler
* clone the repository or pull the latest copy
* create a branch and make a small change
* commit, push, and open a pull request

### Suggested Schedule

| Time | Topic | Description |
| - | - | - |
| 09:00 - 09:30 | Welcome | Introduction to the company, internship goals, and expected workflow. |
| 09:30 - 10:30 | Machine setup | Verify Git, editor, Python, and C++ compiler. |
| 10:30 - 11:15 | Repository access | Confirm GitHub access and clone the repository. |
| 11:15 - 12:00 | First Git commands | Check branch, status, pull, and create a branch. |
| 12:00 - 13:00 | Lunch | Break. |
| 13:00 - 14:00 | First code change | Run and edit a small Python or C++ file. |
| 14:00 - 15:00 | Push and pull request | Push the branch and create a pull request. |
| 15:00 - 15:30 | Recap | Discuss common issues and prepare for Day 2. |

### Practical Task

1. Verify the tools from [../docs/setup-guide.md](../docs/setup-guide.md).
2. Clone the internship repository if needed.
3. Create a branch such as `student/your-name-day-1`.
4. Edit one of the starter exercise files.
5. Run the program locally.
6. Commit with a clear message.
7. Push the branch.
8. Open a pull request and request mentor review.

### Deliverables

At the end of Day 1, each student should have:

* a working local repository
* one branch pushed to GitHub
* one small code or documentation change
* one pull request
