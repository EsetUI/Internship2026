## Day 2 - Git And Teamwork

Day 2 focuses on working in a shared repository without stepping on each other.

### Goals

Students should practice:

* reading `git status` and `git log`
* pulling the latest changes from `main`
* creating a new branch for a new task
* reviewing another person's pull request
* resolving simple merge or conflict situations with mentor help

### Suggested Schedule

| Time | Topic | Description |
| - | - | - |
| 08:30 - 08:45 | Recap | Review the Day 1 workflow and common mistakes. |
| 09:00 - 09:10 | Branch practice | Create a fresh branch and repeat the workflow. |
| 9:10 - 9:30 | Pull requests | Read, comment on, and discuss review feedback. |
| 9:30 - 10:00 | Merge basics | Understand local branch vs remote branch vs main. |
| 10:00 - 11:00 | Lunch | Break. |
| 11:00 - 12:00 | Conflict demo | Mentor shows a simple merge conflict and how to resolve it. |
| 12:00 - 13:00 | Teamwork task | Students make a small shared documentation or exercise change. |
| 13:00 - 14:30 | Recap | Summarize what safe collaboration looks like. |

### Practical Task

1. Pull the latest `main` branch.
2. Create a new branch for Day 2.
3. Improve one README or exercise file.
4. Open a pull request with a short description.
5. Review another student's pull request.
6. Apply one round of feedback to your own branch.

### Deliverables

* one new branch
* one pull request update after review
* at least one review comment on another pull request
