## Day 5 - Shared Task 3: Text Summary

Day 5 uses the same text analysis assignment in Python and C++ so both interns can compare implementation choices directly.

### Goals

Students should practice:

* implementing the same user-facing behavior in Python and C++
* structuring code with clear functions
* handling invalid input safely
* improving console output and usability
* explaining implementation choices in a pull request

### Suggested Exercises

Use these files from [../cpp-exercises/README.md](../cpp-exercises/README.md):

* `04_text_summary.cpp`
* and the matching Python file `../python-exercises/04_text_summary.py`

### Shared Requirements

Both implementations should:

* ask the user for a sentence or short paragraph
* reject empty input
* print character count
* print word count
* print vowel count

### Practical Task

1. Implement the same text summary behavior in Python and C++.
2. Run both versions with the same sample inputs.
3. Compare formatting, counts, and empty-input handling.
4. Commit and push both changes with clear descriptions.

### Good Challenge Ideas

* ignore punctuation consistently
* add sentence count or unique word count
* extract helper functions for repeated logic
* improve prompts and result formatting
* document build and run steps in the pull request

### Deliverables

* one Python implementation and one C++ implementation of the same task
* two reviewable pull requests with comparable behavior
